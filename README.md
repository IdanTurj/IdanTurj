#### [Supplier Payments Analysis](https://github.com/IdanTurj/supplier-payments-analysis)
**PostgreSQL · SQL · Power BI**

#### [Trading Performance Analytics Dashboard](https://github.com/IdanTurj/trading-performance-analytics-dashboard)
**Python · Pandas · Streamlit · Plotly**

Built an interactive dashboard for exploring trading-simulation results, comparing strategy configurations, and analyzing performance and risk indicators.

**Python · Pandas · Matplotlib**

Developed a reproducible backtesting workflow with trade-level analysis and KPIs including win rate, net P&L, return, profit factor, final balance, and maximum drawdown.
